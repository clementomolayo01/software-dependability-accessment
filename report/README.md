## 📘 Project Report

This project was developed as part of the *Software Dependability* course at the University of Salerno.

The full project report, written in the ACM proceedings LaTeX format, is available at:

- [`report/main.pdf`](report/main.pdf) (generated from `report/main.tex`)

The report describes:
- the architecture of the URL Shortener;
- our dependability requirements;
- the use of testing, coverage, mutation testing, JML, security scanning, and performance benchmarking;
- the quantitative results and lessons learned.
